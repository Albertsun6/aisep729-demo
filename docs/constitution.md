# 工程宪法（Constitution）

> 项目级不可妥协原则。修宪 = 独立 ADR。每条：原则 + 为什么 + 可执行检查。
> 本文件由 `e2e init` 生成骨架，请按项目实际增删（建议 ≤15 条）。

- **C1 未过门禁不进下一段**。为什么：门禁是人介入边界。检查：skill 第 0 步探针 `--gate-only`，退出 64 即拒绝。
- **C2 能用可执行验证的绝不用"我觉得对了"**。为什么：只有可执行验证真正约束 agent。检查：每阶段制品有 check-*.sh 且交付前强制跑。
- **C3 安全边界只认服务端强制**。hooks/CLAUDE.md 是本地快反馈与建议；硬策略=permission system + 受保护分支 + CI required checks。
- **C4 产物是真相，工具是适配**。`specs/` `docs/` 放仓库根；`.claude/` 不放业务真相。
- **C5 一事一 ADR，决策必含 ≥2 真实备选，不可变只追加**。
